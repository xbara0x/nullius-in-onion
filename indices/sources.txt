# One source per line:  Name | URL-or-path | kind
# Remote list sources are fetched once per run through the Tor proxy; local paths
# are read from disk, relative to this file. Kinds (what "listed by" means):
#   curated        a person verified the identity behind the address
#   crawler        a robot reached the address once; nothing about identity
#   institutional  the operator itself publishes the address
#   tracker        a thematic tracker maintains it
#   community      a list curated by pull request
#   search         a search engine queried per target ({query} in the URL)
#   research       a published measurement dataset; the card says what an entry proves
# Every source has a card in SOURCES.md; the bar for adding one is in
# CONTRIBUTING.md. Check them all with:  nullius indices --registry
